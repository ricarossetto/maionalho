# MAIONALHO® 2.0

**O ALHO TOMOU O PODER.**

Uma landing page conceitual, exagerada e completamente original, feita para demonstrar experiências web avançadas sem frameworks pesados e sem build step.

## Tecnologias

- HTML5 e CSS moderno, em um único \`index.html\`;
- Three.js via CDN ES Modules, com pote de Maionalho modelado e iluminado proceduralmente em WebGL;
- Canvas 2D para rótulo renderizado dinamicamente;
- Web APIs nativas para interações, sliders, reveal por scroll, tema dos sabores e animações;
- responsividade para Safari iOS, movimento reduzido e fallback sem WebGL.

## Interações

- Arraste o pote para girar (mouse / toque).
- Faça zoom com scroll ou pinça no iPhone.
- Troque as edições conceituais e observe a alteração do rótulo.
- Ajuste o nível de alho e a instabilidade no Laboratório.
- Pressione **Liberar o caos** para chover alho pela interface.
- Navegue pelas seções com efeitos de scroll e cards interativos.

## Execução

Abra o \`index.html\` via hospedagem estática HTTPS. Não requer Node, Vite ou npm. O renderizador carrega Three.js pelo CDN, então exige conexão de internet. Sem WebGL, é exibido um produto ilustrativo CSS.

**Link de visualização provisória:** https://raw.githack.com/ricarossetto/maionalho/main/index.html

**GitHub Pages:** configure Settings → Pages → Deploy from a branch → \`main\` → \`/(root)\`. Depois disso, a URL deve ser https://ricarossetto.github.io/maionalho/ .

## Histórico e observações

A primeira versão do site está preservada em \`legacy/index-2023.html\`.

Este é um exercício conceitual de design e front-end. Os sabores adicionais, embalagem digital e slogans são fictícios; o projeto não afirma existência de estoque, local de venda, tabela nutricional, ou registro de marca. Conteúdo para demonstração, não uma loja operante.
